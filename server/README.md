# AI 서버 설치 (그록 · 클로드 · 제미나이 연결)

명령어 없이 **Cloudflare 웹 화면에서 클릭만** 하면 됩니다. 무료예요.

## 0. 준비: 비밀키 만들기 (한 번만)
비밀키는 아무도 모르는 긴 글자예요. 나만 알고 있어야 해요.
- 아무 곳에나 **긴 글자**를 직접 적어도 돼요. 영문과 숫자 섞어서 30자 이상을 권장해요.
- 예: `k7Tq2mZ9xR4wLp8sVn3dYc6hBj1eGf5a`
- 이 글자를 **메모장에 따로 보관**하세요. 아래 3번과 5번에서 씁니다.

## 1. Cloudflare 가입
https://dash.cloudflare.com 에서 무료로 가입하세요. (이메일 인증 필요)

## 2. 보관함(KV) 만들기
1. 왼쪽 메뉴 **Storage & Databases → Workers KV** 를 누르세요.
   (메뉴 이름이 조금 다를 수 있어요. 검색창에 "KV"를 치면 찾기 쉬워요.)
2. **Create a namespace** → 이름을 `cleannote` 로 쓰고 만드세요.

## 3. 서버(Worker) 만들기
1. 왼쪽 메뉴 **Workers & Pages → Create → Start with Hello World** (또는 "Create Worker")
2. 이름을 `cleannote-mcp` 로 쓰세요. **Deploy** 를 누르세요.
3. **Edit code** 를 누르세요. 안의 내용을 **전부 지우고**, 이 폴더의 `worker.js` 내용을 **통째로 붙여넣기** 하세요.
4. **Deploy** 를 누르세요.

## 4. 비밀키와 보관함 연결하기
1. 만든 Worker 화면에서 **Settings → Variables and Secrets** 로 가세요.
2. **Add** → 타입 **Secret**, 이름 `SECRET`, 값에 **0번에서 만든 비밀키**를 넣으세요. (Save)
3. 같은 화면 **Bindings → Add → KV namespace**
   - Variable name: `KV`
   - KV namespace: `cleannote` 선택 → Save
4. **Deploy** 를 한 번 더 누르세요. (설정이 적용되도록)

## 5. 주소 만들기
Worker 화면 위쪽에 `https://cleannote-mcp.내이름.workers.dev` 같은 주소가 보여요. 여기에 아래를 붙여서 씁니다.

| 용도 | 주소 |
|---|---|
| **그록 · 클로드 · 제미나이 연결용** | `https://cleannote-mcp.내이름.workers.dev/mcp/비밀키` |
| **휴대폰 청소노트 가져오기용** | `https://cleannote-mcp.내이름.workers.dev/inbox/비밀키` |

`비밀키` 자리에 0번 글자를 그대로 넣으세요. (예: `/mcp/k7Tq2mZ9...`)

## 6. 연결하기
### 그록 (Grok)
1. https://grok.com/connectors 접속
2. **New Connector → Custom** 선택
3. 주소 칸에 **연결용 주소**(`/mcp/` 로 끝나는 것)를 넣고 저장
4. 채팅에서 이렇게 말하세요:
   > "다음주 화요일 오후 2시 래미안 아파트 101동 1203호 입주청소 15만원 비번 1234 청소노트에 넣어줘"

### 클로드 (Claude)
1. claude.ai → **설정 → 커넥터(Connectors)** → **커스텀 커넥터 추가**
2. 이름 `청소노트`, 주소에 **연결용 주소** 넣고 추가
3. 채팅에서 같은 방식으로 말하세요.
   (계정 요금제에 따라 커스텀 커넥터가 안 보일 수 있어요.)

### 제미나이 (Gemini)
제미나이 앱에 **연결된 앱 → 사용자 지정 앱 추가** 메뉴가 있으면 연결용 주소를 넣으세요. 메뉴가 없으면 알려 주세요.

## 7. 휴대폰 청소노트에 연결하기
1. 휴대폰 청소노트 → **⚙ 설정 → 🌐 AI 서버 연결**
2. 칸에 **가져오기용 주소**(`/inbox/` 로 끝나는 것)를 넣고 **주소 저장**
3. AI가 넣은 예약을 보려면 **예약 가져오기**를 누르세요. 가져오면 서버에서는 자동으로 지워져요.

## 주의
- **비밀키와 주소는 남에게 보여주지 마세요.** 주소를 아는 사람은 예약을 넣거나 가져갈 수 있어요.
- 비밀키가 새어 나갔다면 Cloudflare에서 `SECRET` 값을 **새 글자로 바꾸고**, 그록·클로드·휴대폰 주소도 새로 넣으세요.
- 예약 데이터는 휴대폰에 저장되고, 서버 보관함에는 **휴대폰이 가져가기 전까지만** 잠깐 남아요.
