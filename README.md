# 반짝 청소노트

청소 일정 · 고객 · 매출을 관리하는 안드로이드용 앱 (PWA: 홈 화면에 설치해서 쓰는 웹앱)

📱 **앱 주소: https://skmgod.github.io/cleaning-note/**
휴대폰 크롬에서 열고 ⋮ → "홈 화면에 추가 / 앱 설치"

## 기능
- 📅 청소 예약: 건물명·호수·비밀번호, 주간 달력, 완료 체크
- 🏷️ 청소 종류 직접 추가·이름 수정·삭제
- 👥 고객 정보: 이름·주소·연락처·메모, 바로 전화/문자/지도
- 💰 결제 기록: 미수/결제완료, 현금·카드·계좌이체
- 📸 청소 전/후 사진 (휴대폰 카메라·갤러리)
- ⏰ 소요 시간 측정 (시작/종료 버튼 또는 직접 입력)
- 📊 월별 매출, 종류별·결제수단별 통계, 미수금 목록
- 💾 백업 파일 내보내기/불러오기 (설정 화면)

데이터는 **휴대폰 안에만** 저장됩니다. 휴대폰을 바꾸기 전에 꼭 백업하세요.

## PC에서 실행
```bash
node serve.js
```
→ http://localhost:5173

## 휴대폰에 설치하기
앱 설치(홈 화면 추가)와 오프라인 기능은 **https 주소**에서만 동작합니다.

GitHub Pages로 배포돼 있습니다. 코드를 고친 뒤 `git push` 하면 1~2분 뒤 자동으로 반영돼요.

1. 휴대폰 크롬에서 https://skmgod.github.io/cleaning-note/ 열기
2. 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**

같은 와이파이에서 `node serve.js` 실행 후 표시되는 `http://192.168.x.x:5173` 주소로 휴대폰에서 미리 볼 수도 있습니다 (이 경우 설치·오프라인은 안 됨).

## 파일 구조
- `app/` 앱 본체 (index.html, styles.css, app.js, sw.js, manifest)
- `tools/make-icons.js` 앱 아이콘 PNG 생성
- `serve.js` 개발용 로컬 서버
